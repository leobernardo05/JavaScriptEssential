# Learning React

Projeto desenvolvido durante meus estudos de **React** na Coursera, com o objetivo de praticar os principais conceitos da biblioteca e compreender a estrutura de uma aplicação React utilizando Vite.

## Sobre o projeto

Esta aplicação faz parte do meu processo de aprendizado em desenvolvimento web com React. O projeto foi utilizado para colocar em prática conceitos fundamentais da biblioteca, como:

* Criação e organização de componentes;
* JSX;
* Props;
* Gerenciamento de estado;
* Eventos;
* Renderização de elementos;
* Hooks;
* Organização de uma aplicação React;
* Estilização com CSS;
* Estrutura de projetos utilizando Vite.

## Tecnologias utilizadas

* React
* JavaScript
* HTML
* CSS
* Vite
* Node.js
* npm

## Como executar o projeto

### 1. Clone o repositório
```bash
git clone https://github.com/leobernardo05/JavaScriptEssential/
```

### 2. Acesse a pasta do projeto

```bash
cd learning_react
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
npm run dev
```

Após executar o comando, o Vite disponibilizará a aplicação localmente, normalmente em:

```text
http://localhost:5173
```
